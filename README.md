## Principles I build around

- **Capability is not authority.**
- Consequential agent actions should cross an enforceable authorization boundary.
- Human accountability should be explicit before deployment, not improvised after an incident.
- Governance should be executable, observable, testable, and capable of producing evidence.
- AI adoption should improve measurable workflow outcomes—not merely add AI to an existing process.
- Public examples should be synthetic and reproducible; employer and client data do not belong in an open repository.
